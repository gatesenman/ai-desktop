## 1. 背景与问题

Windows 桌面是大多数办公用户的「临时工作台」：下载的文件、微信/QQ 接收的文件、截图、安装包都会落在桌面。调研和自测中反复出现的痛点：

1. **找不到**：文件名混乱（「需求文档 (1).pdf」「最终版2.docx」「微信图片_2026…」），只记得内容或大概时间，却想不起名字。
2. **整理成本高**：Fences 类工具能分区，但要先手动建格子、一个个拖；规则需要手写，普通用户不会写正则。
3. **越堆越多**：重复文件、装过的安装包、几个月没碰的文件长期占着桌面和磁盘，没人提醒。
4. **AI 用不起来**：Copilot 等通用助手不了解「我的桌面上有什么」，也不能直接整理桌面。

**机会**：桌面整理工具天然掌握「文件清单 + 用户整理行为」，适合做一个**懂你桌面的 AI**，把「整理、查找、清理」从手工劳动变成一句话或一次确认。

## 2. 产品定位

> **一句话**：Fences 级别的桌面分区体验 + 会自己整理、能听懂人话的本地优先 AI 助手。

- **对用户**：桌面永远整齐；想找的文件一句话找到；该清理的东西有人提醒。
- **差异化**：
  - 比 Fences：多了 AI（自动分组并解释理由、自然语言规则、内容搜索、清理建议），且免费、中文优先。
  - 比腾讯桌面整理 / 360 桌面助手：没有广告和资讯推送；视觉更克制（Fences 风格）；AI 能力是核心而不是附加。
  - 比 Windows Copilot / 通用 AI：专注桌面场景，所有操作可预览、可撤销；默认只发送文件名，可完全本地运行（Ollama）。
  - 比 Raycast / PowerToys Run：不仅是启动器，还负责桌面布局和长期整洁。
- **设计原则**：
  1. **先建议，后执行**：AI 输出的是「计划」，用户确认后才执行；整理类操作都可撤销。
  2. **不移动文件为默认**：格子是虚拟分组，只有用户明确选择「归档」「回收站」「重命名」才动文件。
  3. **本地优先，最小化上传**：能本地做的（重复检测、内容索引、待办提取）绝不上云。
  4. **没有 Key 也能用**：每个 AI 功能都有本地降级路径。

## 3. 目标用户与场景

| 用户 | 画像 | 典型场景 | 核心诉求 |
|---|---|---|---|
| 办公白领（主力） | 每天收发大量文件，桌面 50~200 个图标 | 周一早上桌面一团乱；找「上周客户发的报价单」 | 一键整理、快速找到 |
| 学生 / 研究者 | 论文、课件、截图多 | 期末找某门课的资料；截图堆积 | 按课程/项目分组、内容搜索 |
| 设计 / 运营 | 素材、设计稿、导出图 | 同一项目的 psd/png/文档散落 | 项目归组、大文件清理 |
| 开发者 / 极客 | 熟悉 Fences、Raycast | 想用命令和规则掌控桌面 | 规则引擎、命令栏、本地模型 |
| 家庭 / 长辈电脑 | 不懂整理 | 桌面图标铺满屏幕 | 傻瓜式一键整理、清理提醒 |

**关键场景（用户故事汇总）**
- 作为白领，我希望**打开电脑时看到一份简报**，知道桌面上新增了什么、有什么该处理。
- 作为任何用户，我希望说一句「**把所有发票放到财务格子**」，以后新发票也自动进去。
- 作为忘了文件名的人，我希望搜「**甲方要求的交付周期**」就能找到那份 PDF。
- 作为桌面杂乱的人，我希望工具**告诉我哪些是重复的、装过的、半年没动的**，确认后一键处理。

## 6. 功能路线图

### P0 — 核心 AI（1.2.0，已实现）

#### P0-1 AI 整理建议（可解释 + 学习纠正）
- **用户故事**：作为桌面杂乱的用户，我想一键得到「按用途分组」的整理方案，并知道**为什么**这样分，我可以改了再应用。
- **交互**：托盘 / 格子菜单 / 命令栏 › 「AI 整理建议」› AI 工作台卡片式预览：每组显示图标、可编辑的名称、文件数、一句话理由、文件列表；勾选组 › 「应用所选分组」› toast 带「撤销」。
- **学习纠正**：用户把 AI 分错的文件拖到别的格子，记录「文件 › 格子」作为偏好，下次请求时随提示一起发送；同类文件被连续纠正 2 次，弹出「以后 .psd 都放进设计稿？」一键生成规则。
- **降级**：无 Key 时按「用户规则 › 文件类型」本地生成方案，界面一致，标注「本地规则」。
- **验收**：3 秒内出现骨架/加载；应用后格子内容与预览一致；撤销完全恢复。

#### P0-2 自然语言规则
- **用户故事**：作为不会写正则的用户，我想说「把所有发票放到财务格子」「超过 90 天的文档放待清理」就生成规则。
- **交互**：设置 › 整理规则 顶部输入框 + 示例 chip › 生成「草稿规则」卡片（条件可视化、命中当前桌面 N 个文件的测试结果）› 「保存并应用」。命令栏中同样可用。
- **规则能力**：条件字段 扩展名 / 名称关键词 / 正则 / 类型 / 修改时间 / 大小 / 文件或文件夹；全部满足或任一满足；优先级拖动排序；新文件自动归位。
- **降级**：本地解析器覆盖常见句式（「把…放到…格子」「超过 N 天」「大于 N MB」「.xxx 文件」）。

#### P0-3 桌面清理建议
- **用户故事**：作为桌面越堆越多的用户，我想知道哪些文件可以删，并安全地处理掉。
- **检测（全部本地）**：重复文件（大小相同 › 内容哈希确认）、装过的安装包、大文件（>200MB）、长期未动（>90 天）、临时文件（~$、.tmp、.crdownload）、空文件夹。
- **交互**：顶部「可释放空间」大数字 + 分类统计；分组列表默认勾选低风险项（重复、临时、安装包）；三种处理：放入「待清理」格子（只标记）/ 归档到「桌面\归档\年-月」（可撤销）/ 移到回收站（二次确认）。
- **原则**：永不直接永久删除。

#### P0-4 AI 命令栏
- **用户故事**：作为效率用户，我想在搜索框里直接输入「整理桌面并保存快照」「把发票放到财务格子」「切到第二页」。
- **交互**：快速搜索（Alt+Space）中，输入像命令的句子（或以 `>` 开头）时顶部出现「执行命令」行 › Enter 生成**执行计划**（编号步骤 + 图标 + 说明）› 再按 Enter 执行 / Esc 取消 › toast 汇总并提供撤销。
- **动作集**：整理、AI 整理、新建格子、移动文件到格子、创建规则、隐藏/显示、切换桌面页、保存/恢复快照、清理、重命名、简报、总结/翻译文件、搜索、撤销、打开设置。
- **降级**：本地模式识别常用句式；无法识别时退化为搜索。

#### P0-5 内容搜索（本地索引 + 可选语义）
- **用户故事**：作为记不住文件名的人，我想按内容找文件。
- **实现**：本地提取 txt/md/pdf/docx 等文本 › 分词（英文单词 + 中文二元组）› BM25 倒排索引，存于本机用户目录；文件变化增量更新。可选配置 embeddings 模型（推荐 Ollama `bge-m3` / `nomic-embed-text`），做「关键词 + 向量」混合排序。
- **交互**：搜索结果新增「内容匹配」分区，显示命中片段；设置中显示索引状态、可重建。
- **隐私**：默认纯本地；只有用户主动配置 embeddings 接口时才发送文本片段（配置本地 Ollama 则仍不出本机）。

#### P0-6 文件总结 / 翻译 / 问答（已有能力补齐入口）
- 右键文件「AI 总结」「AI 翻译」› AI 助手面板流式输出；可继续追问。命令栏「总结一下报价单」也可触发。
- 只在用户主动触发时发送文件内容（截断至安全长度），面板中明确提示。

## 7. 交互设计总则

1. **统一入口**：AI 工作台（托盘「AI 工作台」/ 设置 › AI 功能 / 命令栏），四个标签页：今日简报、AI 整理建议、桌面清理、批量重命名。
2. **计划 › 确认 › 执行 › 撤销**：所有 AI 写操作都先展示计划；执行后 toast 带「撤销」；文件级操作（归档、重命名）有独立撤销日志。
3. **可解释**：分组给理由、清理给原因（「与『团队合影.jpg』内容完全相同」）、重命名给理由、规则给命中数量。
4. **来源标识**：每个结果标注「AI 生成 / 本地规则 / 本地扫描」，让用户知道是否联网。
5. **等待体验**：骨架/三点动画 + 文案说明正在做什么；超时自动降级到本地结果并说明原因。
6. **视觉**：沿用 Fences 风格设计系统（半透明面板、Remix Icon 字体图标、无 emoji），深浅色主题一致。

## 8. 隐私与本地优先策略

| 数据 | 是否离开本机 | 说明 |
|---|---|---|
| 文件名、类型、大小、修改时间 | 仅在使用 AI 整理/命令/重命名/简报时发送到用户配置的接口 | 不含路径中的用户名（只发文件名） |
| 文件内容 | **默认不发送**；仅在用户主动「总结/翻译/问答」或重命名时勾选「参考文件开头内容」时发送 | 截断长度；界面明示 |
| 内容索引 | 永不上传 | 存于本机用户目录，可一键重建/删除 |
| 向量（embeddings） | 仅在用户配置 embeddings 模型时，发送文本片段到该接口 | 推荐 Ollama 本地模型 |
| 清理扫描、重复检测、待办提取 | 永不上传 | 纯本地计算 |
| 使用统计 | 不收集 | 未来如收集，需显式同意且匿名 |

**本地模型方案**：任何 OpenAI 兼容接口都可用。推荐 Ollama：对话 `qwen2.5:7b`（整理/命令/重命名足够）、embeddings `bge-m3`。把 Base URL 设为 `http://localhost:11434/v1` 即可实现**全部数据不出本机**。

## 9. 指标体系

| 类别 | 指标 | 目标（上线 3 个月） |
|---|---|---|
| 北极星 | 周活跃用户中「桌面整洁度」提升（桌面散落图标数下降）| 平均下降 40% |
| 采纳 | AI 整理建议的应用率（应用组数 / 建议组数） | ≥ 60% |
| 质量 | AI 整理被纠正率（7 天内被手动移动的文件比例） | ≤ 15% |
| 质量 | 应用后撤销率 | ≤ 10% |
| 规则 | 自然语言规则生成成功率（生成后被保存） | ≥ 70% |
| 搜索 | 搜索后打开文件的比例；内容匹配被点击占比 | ≥ 75%；≥ 15% |
| 清理 | 每用户每月释放空间 | ≥ 500 MB |
| 命令栏 | 命令计划被执行的比例 | ≥ 65% |
| 降级 | 无 Key 用户的 7 日留存 vs 有 Key 用户 | 差距 ≤ 10pp |
| 性能 | AI 整理首屏时间（P90） | ≤ 8s（云端）/ ≤ 15s（本地 7B） |

指标均可本地计算后展示给用户本人（「本月为你释放了 1.2GB」），不依赖上报。

## 10. 风险与对策

| 风险 | 影响 | 对策 |
|---|---|---|
| AI 分类不准 / 胡编文件 | 用户失去信任 | 只允许返回已有文件编号；先预览后应用；可撤销；学习纠正 |
| 误删文件 | 严重 | 不提供永久删除；回收站二次确认；归档和重命名可撤销 |
| 隐私顾虑 | 拒用 AI | 默认只发文件名；来源标识；Ollama 本地方案；隐私说明页 |
| 没有 API Key | AI 功能空转 | 每个功能有本地降级；首次引导介绍国内可用服务和 Ollama |
| 模型成本 / 延迟 | 体验差 | 只发元数据（几 KB）；批量合并请求；超时降级 |
| Windows 桌面层兼容（WorkerW、多显示器、DPI） | 格子显示异常 | 原生辅助进程 best-effort；按分辨率保存布局；快照恢复 |
| 与 Fences 等工具冲突 | 双重整理 | 检测到同类工具时提示 |
| 命令栏误执行 | 意外操作 | 计划必须确认；危险动作（删除）不在命令集内 |
