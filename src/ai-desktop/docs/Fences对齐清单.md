# AI 桌面工作台 × Stardock Fences 功能对齐清单（v1.3.5）

> 资料来源（2026-10 复核）：Stardock Fences 6 官方功能页 `stardock.com/products/fences/features`、Fences 6 发布公告（2025-05）、6.20 更新博客（2025-12）、6.46 / 6.52 / 6.54 / 6.58 更新日志（2026-04 ~ 2026-10）、Fences 5/6 帮助文档（Layout / Personalization / Quick-Hide / Rules / Peek / Folder Portals / Tabs）。
>
> 状态说明：✅ 已具备（旧版本已有） · 🆕 1.3.x 新增或补齐（说明以「1.3.2：」开头的是本版新增） · ◐ 部分对齐（有替代实现） · ✖ 不可行 / 不做（附原因）
>
> **1.3.5 变化摘要**：拖放对齐 Fences / 腾讯桌面整理——拖入与格子间移动只改归属（引用），不复制文件；拖到空白桌面移出格子；仅 Ctrl+拖 走系统复制；格子内排序不重复。映射格子仍按资源管理器语义。
>
> **1.3.4 变化摘要**：体验打磨——格子毛玻璃与阴影更柔、标题栏层次、空状态与卷起/窥视过渡、图标选中/悬停、三种标签样式与通知/设置/命令栏视觉统一；功能对齐面与 1.3.3 相同。
>
> **1.3.2 变化摘要**：上一版的 3 个 ◐ 项中，「标签样式与颜色」「隐藏映射格子标题栏图标」已补齐为 🆕；「图标着色」做到了格子内全部可行的部分（全局着色 + 颜色 + 强度），只剩“给资源管理器散放图标着色”这一不可行部分，仍标 ◐。另新增「2.6 键盘与选择」一节，并加强了异常处理（见第 8 节）。

## 8. 技术实现说明（1.3.0，1.3.2 补充）

- **1.3.2 健壮性**：
  - 配置文件（layout / settings / snapshots 等）写入改为“临时文件 + fsync + 原子重命名”，并每 5 分钟最多保留一份最近可用的 `.bak`。
  - 读取时如果 JSON 损坏：先把原文件另存为 `*.corrupt-时间戳`，再自动从 `.bak` 恢复；没有备份才使用默认值。启动后会弹出提示，不再静默丢失布局。
  - 原生助手 exe 和 PowerShell 回退都失败时，只弹出一次提示，说明哪些功能暂时不可用，其余功能照常运行。
  - 打开已被外部移动或删除的文件时，提示“文件已不存在”并刷新；格子或面板的渲染进程崩溃后会自动重新加载。
  - 主进程加了兜底的未处理异常日志，避免意外异常导致整个桌面消失。

- **原生助手 `AIDeskHelper.exe`**（C# 5，.NET Framework 4.x，Win10/11 自带运行时，约 28 KB）：常驻一个 STA 消息循环，通过 JSON 行协议走 stdin/stdout，提供低级鼠标钩子（双击、右键、拖框）、桌面图标坐标与选中项（IFolderView）、原生 IContextMenu、窗口沉底/嵌入、隐藏桌面图标、已知文件夹路径。exe 无法启动时，自动退回 PowerShell 5.1 `Add-Type` 编译同一份源码。空闲时 CPU 约为 0（只有事件驱动的钩子回调，拖动事件 ≥15 ms 节流）。
- **桌面路径**：以助手返回的已知文件夹（含 OneDrive 重定向）为准，再依次回退到 Electron 路径、%OneDrive%\Desktop、%USERPROFILE%\Desktop；公用桌面使用 %PUBLIC%\Desktop；路径去重时不区分大小写。
- **测试**：几何命中、规则、IPC 通道审计做单元测试；Linux 上用模拟助手（同一协议）跑冒烟测试，覆盖拖框建格子、选中项建格子、原生菜单往返、三种快速隐藏模式、锁定全部、复制外观。
- **未在真实 Windows 上验证的部分**：钩子吞掉/回放点击、跨进程 LVM_HITTEST、IFolderView、IContextMenu 菜单消息转发。这些代码已经用 mono 编译，协议在 mono 下测过，但需要用户在 Win10/11 上实测。
