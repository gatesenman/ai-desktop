# Stardock Fences 调研笔记（2026-10）

来源：stardock.com/products/fences、Stardock 帮助中心（Fences 6 UI: Tabs / Peek）、Fences 6 发布公告、Themia《Stardock Fences 6 Review (2026)》。

当前版本为 **Fences 6**（Fences 5 的能力全部保留）。售价约 $29.99（一次性）或订阅。

## 核心能力
| 能力 | 说明 | 本项目对应 |
|---|---|---|
| Fence 分组 | 桌面上的半透明「阴影区域」，收纳图标 | 格子（低边框半透明面板） |
| Roll-up 卷起 | 双击标题栏卷起为仅标题；鼠标悬停临时展开 | 卷起 + 悬停预览（Peek on hover） |
| Quick Hide | 双击桌面空白处隐藏所有图标和 Fence | 双击桌面隐藏/显示，可按格子排除，并可同时隐藏系统桌面图标 |
| Folder Portals | 把任意文件夹（含网盘/网络盘）镜像到桌面，可进入子文件夹浏览 | 文件夹映射格子 + 面包屑导航 |
| 规则自动整理 | 按文件类型、名称、时间、目标位置等规则自动把新图标放入 Fence | 可编辑规则（扩展名/名称/正则/日期/大小/类型）、优先级、新文件自动归位 |
| Desktop Pages | 桌面变成多页，每页有自己的 Fence，滑动切换 | 多桌面页 + 快捷键切换 + 页码指示器 |
| 布局快照 | 保存/恢复布局；分辨率变化时按分辨率恢复 | 命名快照 + 按分辨率自动布局 |
| Peek | Win+Space 把 Fence 临时带到所有窗口之上 | Peek 快捷键（Win 组合键被系统占用，默认 Alt+Shift+F） |
| Tabs（6 新增） | 把一个 Fence 拖到另一个上组成标签组 | 未实现（列入后续） |
| Icon Tint（6 新增） | 给图标统一着色，降低视觉噪声 | 格子级「图标着色」 |
| Chameleon | 图标平时淡出，鼠标靠近再显现 | 「变色龙」淡出模式 |
| 个性化 | 大小、颜色、透明度、标签样式、排序 | 每格子颜色/着色强度/透明度/标题样式/对齐 |
| 锁定 | 锁定 Fence 位置防误拖 | 锁定位置和大小 |
| 对齐 | 拖动时吸附网格、彼此对齐 | 吸附网格/格子边缘/屏幕边缘 + 对齐参考线 |

## 视觉风格
- 默认是深色半透明「阴影区」，几乎没有边框，与壁纸融合；标题是一条窄带，**标题文字居中**，白色带阴影。
- 图标与系统桌面图标一致：大图标 + 白色文字 + 文字阴影；选中为半透明白色高亮框。
- 选项按钮平时隐藏，鼠标悬停标题栏才出现。
- 颜色是对整个 Fence 背景着色，而不是只给标题上色。
